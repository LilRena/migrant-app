# KFU Migrant

Веб-приложение для иностранных студентов КФУ и сотрудников миграционного центра.
Подробное задание, этапы и модель данных — в `TZ.md`. Работай по нему и не выходи за его рамки.

## Что делаем сейчас

Серьёзно (бэкенд + база + фронтенд) делаем только раздел **«Документы»**: студент видит шаги алгоритма со сроками, загружает документ, сотрудник проверяет. Главная и Профиль — макеты на демо-данных. Очередь, чат, push, мультиязычность — не делаем.

## Стек

Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL, Pydantic v2, JWT (python-jose), bcrypt, pytest. Фронтенд: HTML + CSS + чистый JS (ES-модули), все запросы через `frontend/js/api.js`.

## Правила

- Работай по этапам из `TZ.md`. После этапа остановись, запусти тесты и отчитайся по каждому пункту этапа отдельно: сделано / не сделано / сделано иначе и почему. Общие фразы вроде «добавил проверки» не принимаются, показывай реальный код.
- Не добавляй функции, которых нет в ТЗ. Если неясно, спроси.
- Репозиторий публичный. Секретов в коде нет: всё через `.env`, у `SECRET_KEY` и `DATABASE_URL` нет значений по умолчанию, без них приложение не стартует. В `.gitignore` всегда есть `.env` и `uploads/`.
- Любой эндпоинт, который читает или меняет данные студента, ищет запись сразу по `id` И по владельцу (`student_id == current_user.id`). Не «найти, потом проверить». На это пишутся тесты.
- Эндпоинты сотрудника доступны только роли `staff`.
- Даты хранятся типом `Date`/`DateTime`, не строками.
- Загрузка файлов: только PDF/JPG/PNG, до 10 МБ, случайное имя файла, хранение вне публичной папки.
- Реальных сроков миграционного центра пока нет. Шаги и правила сроков лежат в `data/steps_demo.json`; это шаблон, который потом заменят реальными данными без изменения кода.
- Тексты интерфейса на русском. Код, имена переменных и комментарии на английском; комментарии короткие и понятные новичку.
- Автор проекта учится программировать: объясняй коротко, зачем сделано то или иное решение, когда оно не очевидно.

## Команды

Заполнить после Этапа 0: запуск сервера, тесты, миграции, загрузка шагов, создание сотрудника.
